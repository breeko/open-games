Converted sprite/animation data and textures obtained from:
https://github.com/wicked-knife/KingdomRushWeb
Commit 3e4eac4110ce0e228f1300ca145cd7c29d2dbc8a

commit 4072b18bf4e418eec8b813a960c83003744cb710.

has not been verified. Their gameplay buffs and 330-gold economy are not used.

Original artwork rights are separate from any code/converter license.

unofficial reference prototype; original-pixel and retail balance fidelity

See docs/games/kingdom-rush/README.md, progress.md, and reference-manifest.json
in the source project for verification scope, source hashes and limitations.

Maps 1–2 use the same pinned geometry and visual sources above. Campaign wave
parameters and starting gold were transcribed from the publisher-hosted Flash
v1.13 binary, SHA256 7b5467a3eccc17f6dd001ff2d41bdf1b03d79fd515a2a9586c42bfd982bb1e23.
The original executable and ActionScript are not distributed with this project.
See level01-manifest.json and level02-manifest.json for per-file input hashes.

Twin Rivers Pass (map 4) uses the same pinned visual source. Paths, sites,
campaign waves, cash and new combat facts target the pinned Flash v1.13 binary.
See level04-manifest.json and twin-rivers-pass.md in the source documentation.

Silveroak Forest (map 5) uses the same pinned visual source. Original numeric
paths, waves, existing archer tower, elf camp and enemy facts target Flash v1.13.
See level05-manifest.json and silveroak-forest.md in the source documentation.

The Citadel (map 6) uses the same pinned visual source. Original paths, sites,
waves, advanced mage and enemy/boss numeric facts target Flash v1.13.
See level06-manifest.json and the-citadel.md in the source documentation.

Ranger/Arcane skills and the power star-upgrade chains use factual numeric
research from the same Flash v1.13 binary. See skills-manifest.json and
skills-and-power-upgrades.md in the source documentation for rules and limits.

Campaign navigation uses map_background_kr1 and map_flag_0020 from the same
pinned KingdomRushWeb visual export (data/map_kr1). This is the later colored
map artwork, not the Flash v1.13 parchment map. Flag spacing, route overlay,
English briefings and navigation are authored for this prototype. All six
implemented maps remain unlocked. See campaign-map-manifest.json in docs for
input hashes and scripts/games/kingdom-rush/prepare-campaign-map.py for extraction.
